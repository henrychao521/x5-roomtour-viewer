去霧方法

3DGS 的每一顆高斯本質上就是帶屬性的 3D 粒子，剛好對上 OpenFPM 的核心——GPU 上的粒子鄰域搜尋（cell-list）。 這條線把「掃描出來的空間」餵進「新的 3D 運算分析方式」，做三件事：(1) 用 GPU 快速算每顆高斯的鄰域密度並與現行 CPU 管線逐點驗證； (2) 用局部表面變異度分開「該留的薄面」與「該去的雲霧」，實作五種去霧法比較成效；(3) 把清理後的空間當邊界，在真實教室裡跑 SPH 流體。

① 底層：OpenFPM Metal GPU 建置驗證

📖 技術說明 — 為什麼是 OpenFPM / Metal，怎麼跑起來的

OpenFPM 5.2.0（2026-07）首度加入 Apple Metal GPU 後端：CUDA 風格 kernel 經 HIP 前端→clspv→SPIR-V→MoltenVK→Metal，原始碼一行不改就能在 Apple Silicon GPU 上跑。本站從源碼在 M4 Max 上編譯跑通（踩過 Boost/HDF5/CMake 等相依坑），並以經典 SPH 壩潰驗證：17 萬顆粒子、完整 1.5 秒模擬，全在 Metal GPU（AGXMetalG16X 驅動確認載入）。

③ 空間雲霧修正：五種方法 × 成效比較

3DGS 的「第一人稱霧」＝三類病態高斯：孤立 floater（低鄰域密度）、針狀高斯（高各向異性，霧的根因）、瀰漫高斯（低不透明度）。 用上面 GPU 算的密度 + 局部表面變異度（鄰居共變異數 PCA），實作並比較五種修正法：

成效排名（以客觀指標為主）

排名以客觀量化指標為準（霧體積↓ + 結構保留 + 是否留洞），而非主觀看圖——原因見下方盲測驗證。

  1. 1L3（貼面 surfel）— 最佳。霧體積降幅最大（−44.3%），且把 5.8 萬顆「薄但貼牆/桌」的高斯壓成對齊表面的圓盤（保結構、不改點數、不留洞）。
  2. 2L2（表面保護）— 穩健。去霧 −41%，保護真表面薄高斯不被誤夾，結構比 L1 完整。
  3. 3L1（各向異性）— 有效但會誤傷。去霧 −42%，但夾到牆/桌面上的薄高斯，細節略損。
  4. 4Level-set（距離）— 去霧俐落但較兇。霧 −40%，幾何移除離表面遠的高斯，但一次刪 29.6 萬顆，偏稀疏、有留洞風險。
  5. 5Auto（自動門檻）— 太保守。只動 1.8 萬顆、霧 −39%，最接近原始；適合當安全基準，門檻需視場景放寬。

盲測 VLM 評分 — 為何「不能只靠 VLM 看圖」（驗證揭露）

用 3 位獨立盲審（不同亂序、路徑不洩漏方法）給六張圖打分，並自帶三重驗證：E1 控制（真原始應被判最霧）、E2 校準（VLM 分數應與客觀霧量正相關）、E3 一致（裁判間排名一致性）。結果三關過不了兩關：

驗證關卡結果說明
E1 控制（raw=最霧）FAIL 0/3三位裁判都把 level-set 誤判為原始，而非真原始
E2 相關（ρ）FAILSpearman ρ=0.54、p=0.27（未達門檻且不顯著）
E3 一致（τ）WEAK平均 Kendall τ=0.29（j1–j2 τ=0.60，j3 離群）
診斷：level-set 移除 29.6 萬顆高斯 → 我們的簡易軟體算圖把稀疏點集畫得更暗/更灰 → VLM 把這個「渲染假影」當成霧，反而判它最霧。也就是 VLM 評的是 2D 渲染、不是 3D 場景——正是多模態模型「靠 2D 先驗、缺真 3D 理解」的已知限制。但有訊號：對不改變點數的夾制類（L1/L2/L3/auto），三裁判一致把它們判得比原始乾淨（方向對）。
可推廣的教訓：①VLM 評 3D 一定要有控制組＋客觀指標校準（本例正是這兩關抓出不可信，否則我就會誤報「L3 最佳=VLM 驗證」）；②凡改變點數/密度的操作，簡易渲染器會產生 VLM 誤讀的假影 → 要用正規 gsplat 渲染器或多視角或成對比較；③成效排名以客觀指標為主、VLM 為輔且需附註。方法細節見 VLM_FOR_3D.md

④ 為何 L2/L3 更準：局部表面變異度

📖 技術說明 — 表面變異度（Pauly）與 GPU 共變異數

做法：在 GPU 鄰域迴圈裡順便累加每顆高斯的鄰居共變異數，host 端用 eigvalsh 求 PCA 特徵值 λ₀≤λ₁≤λ₂，取表面變異度 SV = λ₀/(λ₀+λ₁+λ₂)（Pauly 2002）。低 SV＝鄰居共面（真表面，即使高斯很薄也該留）；高 SV＝瀰漫團塊（霧）。這解決了「薄≠病，不貼面才是病」——單看形狀（各向異性）會把貼在牆上的薄高斯誤當針狀霧。

⑤ 延伸：把水灌進真實教室（SPH × 3DGS）

同一套 OpenFPM，把去霧後的掃描表面當邊界，在真實教室幾何裡跑 SPH 流體——現行管線做不到的能力，對應物理教育情境。

⑥ 工坊 3D 氣流分析（勢流）

既然有完整 3D 幾何，就做 3D 的氣流：在房間 5 萬個空氣體素上解勢流（Laplace ∇²φ=0），窗戶=進氣、天花板排煙管=出氣、牆/地/家具=不透氣，速度 v=−∇φ，再放示蹤粒子畫 3D 流線。窗戶與排煙管位置由使用者在互動點選器上確認（兩側長牆 27 個窗戶點＋中央天花板一排 6 個排煙管點）。

驗證：流場由諧函數 φ 構造 ⇒ 連續意義上不可壓縮（∇·v≈0）；可靠輸出是流向與拓樸（兩側進氣→中央上抽），非局部速度大小（∇·v 離散殘差出現在障礙物邊界）。位置經使用者點選確認。
誠實界線：這是勢流模型估計、非實測——真實氣流還受排風扇動力、門開關、熱浮力、空調影響（那些要完整黏性 CFD／Navier–Stokes）。此處給的是「若窗進、排煙管抽，主對流路徑與方向大致如何」。
去霧部分的誠實界線：粒子法是強力的後處理分析與修正（偵測＋移除/夾制/貼面），不是重建。要「不長出霧」需回訓練期（深度正則／FSGS／DNGaussian）。本頁的去霧屬後處理，與現行 deneedle 同性質，但更快（Metal）、多訊號、且對 CPU 逐點驗證。
