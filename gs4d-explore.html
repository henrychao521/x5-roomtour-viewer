①報告的核心框架（摘要）

報告主張電腦圖形學正從顯式多邊形轉向輻射場（Radiance Fields）：3DGS 把場景表示成數百萬個各向異性高斯橢球（位置、共變異數、不透明度、球諧 SH 編碼視角相依色彩）；4DGS 再加時間維度（變形場 / 時間條件參數 / 顯式 4D 高斯）重現動態。Blender 生態靠 KIRI 3DGS Render、BlendSplat（幾何節點+著色器廣告牌）、SkySplat 等外掛整合，官方也在推原生點雲+Cycles 橢球原語。核心命題＝靜動態分離的 Hybrid 3D-4DGS（靜態環境 3DGS + 動態主體 4DGS，Z-depth 合成），並提了四個前瞻專案（VR 堪景 / AI 合成資料 / Web 體積影音 / 物理特效）。

②報告 vs 我們的實測（誠實對照）

這是本頁最有價值的部分——把報告的技術宣稱對到我們動手驗過的結果：

報告宣稱狀態我們的實測 / 註記
KIRI 3DGS Render 匯入 .ply 到 Blender已驗證可匯入；但渲染只能 GUI（無頭模式不產生幾何、畫面全黑）。見 Blender×GS。
網頁版 splat 含 SH（視角相依色彩）與我們相反我們的網頁匯出是 -H 0 DC-only（剝了 SH）；要 SH 得重訓。
splat-transform 壓縮 / 過濾（SH 帶、裁切、濾飄絲）已驗證實用：-H 0..3 砍 SH 帶、-B 盒裁、-G 濾飄絲、-F 抽稀。今天才用來出 web 版。
深度約束訓練去飄絲 + 保 SH已驗證家政 gsplat --depth-loss --sh-degree 3，1600px+bilateral 後 PSNR 18→22。見 深度正則紀錄。
靜態 3DGS + 動態層 的 Hybrid 概念部分驗證我們有靜態教室 3DGS + 人流軌跡分析；今天做了「物理球（動態）疊在 3DGS（靜態）」雛形（見 ③）。
Apple ML-Sharp「單張影像生成 3DGS」→ 偽 4DGS待查聽起來很強但細節我未證實，動手用前要查。
KIRI 5.0：4DGS .ply 序列 / 代理網格綁定 / 燈光烘焙寫回 SH 重打光待查我們的 5.0 只驗過匯入+GUI 渲染；這些進階功能未實測。3DGS 重打光本質是研究題（GS-IR/Relightable），別預設能用。
Blender 官方原生 GS（點雲+Cycles 橢球原語，#159470）待查方向可信，但成熟度/可用性要查官方進度。
I-frame/P-frame 時序壓縮 4DGS、KHR_gaussian_splatting 標準待查概念合理（類影片編碼）；標準化狀態與工具支援度待查。
一句話：報告的3DGS 現況大致與我們實測吻合（甚至我們在去霧+保SH+web 壓縮上已有可上站成果）；但4DGS 與重打光那一段偏前瞻，多數宣稱要先查證再下注。

②實作雛形

雛形 A · 物理 × 3DGS（對應報告專案 4）

把 CG 物理物件放進去霧 3DGS 教室裡：球受真實重力，地板/牆面的彈跳邊界是從 COLMAP 198,815 個稀疏點擬合地板平面算出來的（floor Y、房間範圍）。這正是報告講的「靜態輻射場 + 動態網格、Z-depth 合成」最小可行版。

🏀 開啟 物理 × 3DGS 雛形 →
✓ 已驗證：3DGS 場景在真實瀏覽器全解析度渲染；物理數值正確（手動積分球會落到地板 Y=−2.22 靜止）；mesh 球體位置即時更新。會在你的前景瀏覽器動起來。
⚠ 環境限制（誠實）：我能驅動的所有瀏覽器情境（無頭預覽、擴充背景分頁）都把 requestAnimationFrame 節流到 0（背景分頁不畫），所以我截不到動畫的圖——但程式邏輯已逐項驗過。請你在前景分頁打開看實際彈跳。
待你確認的點：PlayCanvas 2.10 預設的 gsplat × mesh 深度合成（球被桌子擋住、球擋住後方牆）是否正確——這正是報告點名最難的 Z-depth 問題。若球永遠浮在 splat 前/後，就需要替 gsplat 開深度寫入或自訂混合。

雛形 B · 偽 4DGS / 動態人流（規劃中）

下一個雛形：把真實人流軌跡（我們已有工坊 360 人流落地資料）做成隨時間移動的動態層疊在靜態教室 3DGS 上，加時間軸刷桿——這是報告「Hybrid 3D-4DGS」更貼近教育現場的版本（不需相機陣列）。或用單眼影片逐幀 3DGS 對齊做偽 4DGS 片段。資料已有，待動手。

③對「教育數位孿生」最務實的落點
